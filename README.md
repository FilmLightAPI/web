# FilmLightAPI Enhancements Website

Scripts, shaders, and other enhancements for Baselight, Daylight, and FilmLight API.

VISIT:

[https://filmlightapi.github.io/web/](https://filmlightapi.github.io/web/)

---

Run _build_site.py_ to rebuild the website. It automatically pulls files from the
[FilmLightAPI/enhancements](https://github.com/FilmLightAPI/enhancements) repository and uses the Astro framework to build static HTML for hosting by GitHub.
